# University Website with Chatbot 

Hi, I'm Harshita  
This project is a university website with an integrated chatbot assistant built using HTML, CSS, and JavaScript.

##  Project Overview
This website represents a university landing page where users can explore courses, admissions, and other information.  
It also includes a chatbot named *Nova* that helps users with queries like admissions, courses, fees, hostel, and location.

##  Features
- Responsive university website design
- Navigation bar (Home, Courses, Admissions, Contact)
- Attractive landing section with call-to-action (Apply Now)
- Programs section (BCA, BBA, BCom)
- Integrated chatbot assistant (Nova)
- Interactive chat interface

##  Chatbot Functionality
- Greets users automatically
- Answers basic queries about:
  - Admissions
  - Courses
  - Fees
  - Hostel
  - Location
- Simple rule-based responses using JavaScript

## Tech Stack
- HTML
- CSS
- JavaScript

##  How to Run
1. Download or clone the repository  
2. Open index.html in your browser
